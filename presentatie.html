LSTM-architectuur

Het model leert: gegeven de laatste N tokens, wat komt er hierna?


class LSTMModel(nn.Module):
    def __init__(self, vocab, embed_dim=64,
                 hidden=256, lagen=2, dropout=0.3):
        self.embedding = nn.Embedding(vocab, embed_dim)
        self.lstm      = nn.LSTM(embed_dim, hidden,
                                 num_layers=lagen, ...)
        self.dropout   = nn.Dropout(dropout)
        self.fc        = nn.Linear(hidden, vocab)

    def forward(self, x):
        x = self.embedding(x)          # tokens → vectors
        out, _ = self.lstm(x)          # contextuele verwerking
        return self.fc(self.dropout(   # logits per token
            out[:, -1, :]))

Training

Sliding-window sequenties (venster = 16)


# tokens: [t0, t1, t2, ... t20]
# venster: 16 → oplevert:
X[0] = [t0 … t15],  y[0] = t16
X[1] = [t1 … t16],  y[1] = t17
# ...

Configureerbare hyperparameters

Venstercontext-lengte (standaard 16)
Hidden64 – 512 units per LSTM-laag
Lagen1 – 4 gestapelde LSTM-lagen
Epochsmax 5 – 200 (early stopping)
Geduldstop na N epochs zonder verbetering

🔄 Early stopping

Bewaard het model met het laagste validatieverlies — niet het laatste epoch.

⚡ GPU-ondersteuning

Automatische detectie: Intel Arc (XPU) → NVIDIA (CUDA) → CPU.

✂️ Gradient clipping

Max norm 1.0 voorkomt exploderende gradiënten bij lange sequenties.

Sampling-parameters

🌡️ Temperatuur


probs = softmax(logits / T)
# T = 0.3 → scherpe verdeling
#           (Bach-achtig, voorspelbaar)
# T = 1.5 → vlakke verdeling
#           (creatief, willekeurig)
0.3 → Bach-achtig 1.5 → experiment

🎯 Top-k filtering


# Maskeer alles buiten de top-k
grens = topk(logits, k).values[-1]
logits[logits < grens] = -inf
# → dan softmax over k kandidaten
# k=0: alle tokens
# k=10: alleen 10 beste
Hogere k = meer variatie in de melodie.
